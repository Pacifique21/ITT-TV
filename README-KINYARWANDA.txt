UKO UBISHYIRA KURI GITHUB:
1. Kuramo iyi ZIP kuri mudasobwa.
2. Kanda right-click kuri ZIP, uhitemo Extract All.
3. Fungura repository yawe ITT-NEWZ.
4. Kanda Add file > Upload files.
5. Ohereza index.html, styles.css, app.js na config.js zivuye muri folder.
6. Niba GitHub ibajije gusimbuza files zisanzwe zifite ayo mazina, emera.
7. Kanda Commit changes.
8. Tegereza GitHub Pages, hanyuma ufungure website ukoresheje Ctrl+F5.

ICYITONDERWA CYA RADIO NA TV:
Urutonde rurimo imbuga zemewe za broadcasters, ariko ntabwo buri URL ari direct stream. Radio ikenera direct audio stream URL; TV ikenera direct video/HLS stream URL yemewe. Imbuga zimwe zibuza iframe cyangwa embedding. Ntabwo twashyizemo stream URLs zitagenzuwe cyangwa izihimbano. Kuri config.js, shyira URL yemewe muri stream gusa igihe broadcaster yayitanze kandi yemera ko ikoreshwa kuri website yawe.
